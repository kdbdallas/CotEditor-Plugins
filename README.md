# CotEditor-Plugins
Plugins for the Mac text editor CotEditor

# Install
1. Open CotEditor
2. Click on Scripts menu icon
3. Select "Open Scripts Folder"
4. Place files into the directory that was opened
5. Make sure each one are executable
	- In Terminal: chmod 744 ~/Library/Application\ Scripts/com.coteditor.CotEditor/Format\ Markdown.sh 

# Running Plugin
1. Open the file you wish to format
2. Click on Scripts menu icon
3. Select the plugin for your file type

# Formatting Plugins
- CSS
- HTML
- JavaScript
- JSON
- Markdown
- Ruby
- YAML
